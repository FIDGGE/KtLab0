Выполнил Гончаров Роман ПИ-251
Цель работы:
Освоить базовые конструкции языка Kotlin: синтаксис, типы данных, операторы, функции и классы.

Выполнение работы
Работа оформлена в виде одного файла с точкой входа main(). Пользователь вводит номер задания, после чего вызывается соответствующая функция choice task1()–task10(). Для корректного отображения кириллицы в консоли настроена кодировка UTF-8.

В процессе выполнения использовались переменные val и var, основные типы данных (Int, Double, Long, String), массивы. Из условных конструкций применялись if-else и when; последний удобен тем, что может использоваться как выражение и возвращать значение. Циклы for, while и do-while выбирались исходя из задачи: где требовался перебор коллекции, где — итерация до условия.

Функции объявлялись через fun с параметрами и возвращаемыми значениями. Отдельно стоит отметить инфиксную запись (infix fun), позволившую записывать скалярное произведение векторов в естественном виде a dotProduct b, а также перегрузку оператора * для векторного произведения — это заметно повышает читаемость кода по сравнению с обычными методами.

При работе с классами использовались модификатор open для разрешения наследования, override для переопределения членов класса и конструкторы с параметрами. Иерархия транспорта наглядно демонстрирует, как базовый класс задаёт общее поведение, а наследники его уточняют.

Функции высшего порядка (forEach, forEachIndexed, map, reduce) применялись для обработки массивов. forEachIndexed оказался наиболее удобным в случаях, где одновременно нужны индекс и значение. В ходе работы учтены типовые подводные камни: при перемножении элементов массива накапливание ведётся в Long во избежание переполнения Int; minOrNull() и maxOrNull() возвращают nullable-значения, что корректно обрабатывается для пустых массивов.

Граничные случаи обработаны отдельно: пустой массив, недостаточный размер массива для проверки соседних элементов, вырожденное квадратное уравнение при a = 0.

Выводы
В результате работы освоены базовые конструкции Kotlin. Язык отличается лаконичностью при сохранении читаемости. Наиболее полезными оказались инфиксные функции, перегрузка операторов и конструкция when как замена switch. Получены практические навыки работы с классами, наследованием и функциями высшего порядка. Снизу прикреплены скриншоты выполнения всех 10 заданий.
